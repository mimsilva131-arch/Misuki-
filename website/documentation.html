Documentation

Aprende como utilizar e configurar as principais funcionalidades da Misuki.

🤖 Misuki Bot

A Misuki é um bot para Discord desenvolvido para ajudar na gestão e automatização de servidores.

⚙️ Configuration

As configurações do servidor podem ser geridas através dos comandos disponibilizados pela Misuki.

Os administradores podem configurar diferentes sistemas de acordo com as necessidades do servidor.

🎫 Tickets

O sistema de tickets permite criar canais privados para suporte entre membros e staff.

Os tickets podem incluir ferramentas como transcripts e encerramento de tickets.

⚡ Triggers

Os triggers permitem configurar respostas automáticas quando uma determinada palavra ou expressão é enviada num servidor.

Os triggers podem ser adicionados, editados, ativados, desativados ou removidos.

🛡️ Moderation

As ferramentas de moderação ajudam a equipa de staff a gerir o servidor e a controlar comportamentos inadequados.

🔐 Verification

O sistema de verificação pode ser utilizado para controlar o acesso dos membros e ajudar a proteger o servidor.

📊 Statistics

A Misuki pode disponibilizar informações estatísticas relacionadas com o servidor e a utilização dos seus sistemas.

🔑 Licenses

Algumas funcionalidades da Misuki dependem de uma licença ativa associada ao servidor.

💬 Support

Se precisares de ajuda com a configuração ou utilização da Misuki, consulta a página de suporte.
