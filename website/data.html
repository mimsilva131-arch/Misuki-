Data

Informação sobre os dados utilizados pelos serviços da Misuki.

📊 Data & Storage

A Misuki utiliza dados necessários para disponibilizar e gerir as funcionalidades do bot e dos serviços associados.

🔐 Discord Data

Algumas funcionalidades podem utilizar informações fornecidas pelo Discord, como identificadores de utilizadores, servidores, canais e configurações necessárias ao funcionamento do bot.

⚙️ Configuration Data

As configurações dos servidores podem ser armazenadas para permitir que o sistema mantenha as preferências definidas pelos administradores.

🎫 Ticket Data

O sistema de tickets pode armazenar informações necessárias para identificar e gerir tickets, incluindo informações relacionadas com o servidor e o respetivo utilizador.

⚡ Trigger Data

Os triggers configurados pelos administradores podem ser armazenados para que as respostas automáticas continuem disponíveis no servidor.

🗑️ Data Management

Os dados são utilizados apenas na medida necessária para disponibilizar as funcionalidades correspondentes.

Para informações adicionais sobre privacidade e tratamento de dados, consulta a nossa Privacy Policy .
